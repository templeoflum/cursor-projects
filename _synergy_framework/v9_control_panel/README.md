# Fryng Control Panel

**Status:** 📦 Archived (Synergy Framework v9)

Web-based UI for the synergy system using React + Python.

## Features

- React frontend with tuning slider
- Express.js API backend
- Python management GUI
- 6-step synergy visualization

## Architecture

- `01_build.py` - Creates project structure
- `02_connect.py` - Generates React components
- `03_focus.py` - (Empty placeholder)
- `04_participate.py` - Starts dev servers
- `05_manage.py` - GUI orchestrator

## Usage

```bash
python 05_manage.py
```

Then use GUI buttons: Build → Connect → Participate
