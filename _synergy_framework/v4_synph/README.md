# Synph - File Organization System

**Status:** 📦 Archived (Synergy Framework v4)

File organization and selection GUI for the 6-step synergy workflow.

## Features

- Creates structured directory with 6 steps
- GUI file selector (`load_files.py`)
- CLI file selector (`refine.py`)
- YAML template generation

## Usage

```bash
python node.py        # Create structure
python load_files.py  # GUI selector
```
