# Synergy Dashboard

**Status:** 📦 Archived (Synergy Framework v5)

GUI dashboard with sliders for each of the 6 synergy steps.

## Features

- Offset sliders for each step (-0.2 to +0.2)
- Expansion toggles per step
- Global seed slider (0-1)
- Synergy score visualization

python master_ui_paned.py
