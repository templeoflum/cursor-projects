# Synergy Config Generator

**Status:** 📦 Archived (Synergy Framework v3)

Generates YAML configuration files with mathematically calculated attributes for the 6-step workflow.

## The 6 Steps

1. Potential
2. Symmetry
3. Flow
4. Connectivity
5. Emergence
6. Recursion

## Scripts

Run in sequence:
```bash
python seed.py    # Create folder structure
python pop.py     # Populate with YAML templates
python refine.py  # Add calculated attributes
```

## Notes

This version is complete and working. Generates config files with trigonometric-based attribute values.
