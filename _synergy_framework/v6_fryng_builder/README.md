# Fryng Builder

**Status:** 📦 Archived (Synergy Framework v6)

Project structure generator for the "Fryng" system.

## What It Does

Generates a complete folder hierarchy with:
- `fryng_core/` - Core logic modules
- `ui_core/` - UI components
- Story structures (realms, cultures, characters)
- Foundation rules and steps

## Usage

```bash
python build_node.py  # Generate structure
python run_ui.py      # Launch UI (requires generated structure)
```
