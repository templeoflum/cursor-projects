# Synergy Project Scaffolder

**Status:** 📦 Archived (Synergy Framework v10)

Template generator for synergy projects.

## What It Does

Single script that generates a complete blank project structure:
- Python backend modules
- React UI skeleton
- REST API layer
- Config, database, logging directories

## Usage

```bash
python build.py           # Default: creates node/
python build.py /custom   # Custom output path
```

## Notes

Pure scaffolding - all generated files are empty placeholders with marker comments.
