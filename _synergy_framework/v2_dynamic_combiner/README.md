# Dynamic Combiner

**Status:** 📦 Archived (Synergy Framework v2)

Part of the Synergy Framework exploration. File selector with seed-based attribute mixing.

## Concept

Select YAML files from 5 processing layers, combine them with a seed value (0-1), and calculate dynamic attributes using sine wave fluctuations.

## Files

- `o1_synergy.py` - Main GUI for 5-layer file selection
- `simple_combo.py` - Simpler combiner with seed slider
- `chat.py` - Gemini AI chat module
