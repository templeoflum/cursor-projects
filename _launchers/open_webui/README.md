# Open WebUI Launcher

**Status:** ✅ Working (Launcher Only)

Simple launcher for Open WebUI - a local ChatGPT-like interface.

## Requirements

```bash
pip install open-webui
```

## Usage

```bash
start_ui.bat
# or
python launch_ui.py
```

Opens browser to http://localhost:8080

## Notes

This is just a launcher. The actual Open WebUI application must be installed separately.
