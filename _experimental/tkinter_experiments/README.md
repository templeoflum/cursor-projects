# Tkinter UI Experiments

**Status:** 🧪 Experimental

Collection of Tkinter UI component prototypes and experiments.

## Components

| File | Description |
|------|-------------|
| `code envirnoment.py` | Mini IDE for prototyping Tkinter scripts |
| `polar_slider_center.py` | Linked sliders that sum to 1.0 |
| `hex_test.py` | 6-hexagon attribute visualizer |
| `osc_tes2.py` | Audio oscillator with waveform display |

## Usage

Run any file directly:
```bash
python "code envirnoment.py"
python hex_test.py
python osc_tes2.py
```

## Requirements

- tkinter (built-in)
- numpy
- sounddevice (for audio)

## Notes

These are standalone experiments, not integrated into a single app.
