# Marketing Funnel Visualizer

**Status:** 🧪 Experimental

Desktop app to create and visualize marketing funnels with multiple view styles.

## Features

- 5-stage funnel: Awareness → Engagement → Consideration → Conversion → Retention
- Multiple visualizations: Classic, Horizontal, Animated
- Customize colors and stage names
- Save/load funnels as YAML
- Export to PNG

## Requirements

```bash
pip install -r requirements.txt
```

## Usage

```bash
python funnel_launcher.py
```
