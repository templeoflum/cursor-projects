# LaTeX to PDF Converter

**Status:** ✅ Working

Simple GUI to convert LaTeX code to PDF.

## Requirements

```bash
pip install -r requirements.txt
```

Also requires LaTeX installed on your system:
- Windows: MiKTeX
- macOS: MacTeX
- Linux: texlive-full

## Usage

```bash
python latex_converter.py
```

Paste LaTeX code, click "Convert to PDF", output saves as `output.pdf`.
