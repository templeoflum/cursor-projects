# MythOS v0.1

A prototype symbolic operating system designed for reflective, recursive interaction with language models. MythOS serves as a mythic environment—a digital scroll-chamber where users conduct symbolic rituals, record reflections, and trace emotional echoes across time.

## Core Features

- **Ritual Invocation**: Four symbolic frameworks (GLYPH, MIRROR, SPIRAL, VEIL)
- **Scroll System**: Create and maintain persistent symbolic containers
- **Echo Trail**: Track emotional and symbolic patterns across interactions
- **Memory & Recall**: Tag and retrieve entries based on resonance
- **Sacred Interface**: Terminal-inspired UI for ritual interaction

## Installation

1. Clone this repository
2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run MythOS:
```bash
python mythos.py
```

### Basic Commands

- `/invoke [glyph|mirror|spiral|veil]` - Switch ritual framework
- `/scroll new [name]` - Start a new scroll
- `/scroll open [name]` - Open existing scroll
- `/save [title]` - Save current reflection
- `/recall [tag|word]` - Retrieve relevant entries
- `/veil` - Obscure current output
- `/echo` - Show emotional/symbolic patterns
- `/help` - Show command guide
