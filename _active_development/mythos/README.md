# MythOS

**Status:** 🔨 In Development (v0.1 Prototype)

A symbolic terminal application for reflective, philosophical interaction and journaling.

## Concept

MythOS creates a mythic environment where you conduct "rituals" (thinking modes), record reflections in "scrolls" (journals), and track emotional patterns over time.

## Ritual Modes

- **GLYPH**: Transforms input into symbolic patterns
- **MIRROR**: Reflects words through emotional/psychological lenses
- **SPIRAL**: Explores paradoxes and recursive thinking
- **VEIL**: Cryptic, dreamlike responses

## Two Versions

**mythOS_manus** (Standalone):
```bash
cd mythOS_manus
python main.py
```
Uses predefined responses, no API needed.

**mythoOS_cursor** (AI-powered):
```bash
cd mythoOS_cursor
pip install -r requirements.txt
# Set GOOGLE_API_KEY environment variable
python mythos.py
```
Connects to Google Gemini for actual AI responses.
